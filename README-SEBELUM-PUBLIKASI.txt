PORTOFOLIO K3 / HSE — DESAIN BARU, DATA TERINTEGRASI

Paket ini menggunakan desain baru portofolio K3/HSE dan mempertahankan tampilan visual, tata letak, navigasi, serta galeri pada desain tersebut.

DATA DAN BAGIAN YANG SUDAH DIMASUKKAN
- Profil profesional dan foto profil Kevin Clieff Emor.
- Fokus portofolio K3 / HSE.
- Riwayat pengalaman kerja dan organisasi sesuai data yang tersedia pada rancangan.
- Pembinaan Calon Ahli K3 Umum (AK3U) oleh PT Indotama Jasa Sertifikasi (IJS), Gorontalo, 24 Agustus–4 September 2026.
- Status AK3U ditulis secara hati-hati: lulus pembinaan calon AK3U; sertifikat dan/atau SKP Kemnaker masih dalam proses pada saat surat diterbitkan.
- BNSP Data Management Staff dicantumkan sebagai riwayat kompetensi terdahulu. Dokumen menyebut masa berlaku 3 tahun sejak 28 November 2022, sehingga tidak dinyatakan sebagai sertifikasi aktif.
- 17 sertifikat pelatihan penunjang K3 dari IJS.
- Galeri seminar dan pembelajaran (9 foto).
- Dokumentasi praktik/kunjungan lapangan (1 foto tambahan), foto PKL, dan video PKL.
- Dokumentasi pembukaan pelatihan dan penyampaian materi dari Dinas Tenaga Kerja, ESDM, dan Transmigrasi Provinsi Gorontalo oleh Bapak Wardoyo Pongoliu, Kepala Dinas (4 foto).
- Foto angkatan dan penyerahan sertifikat IJS.

CARA MEMASANG DI GITHUB PAGES
1. Unduh dan ekstrak ZIP ini.
2. Cadangkan isi repositori GitHub Pages yang sekarang.
3. Unggah/ganti file index.html dan folder dokumentasi ke root repositori.
4. Pertahankan nama file dan struktur folder persis seperti di dalam ZIP.
5. Jangan menghapus foto-kevin.jpg.
6. Tunggu proses GitHub Pages selesai, lalu buka situs dan lakukan refresh.
